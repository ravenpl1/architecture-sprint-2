# pymongo-api

## Как запустить

Запускаем кластер mongodb и приложение

```shell
docker compose up -d
```

Настраиваем кластеры и заполняем mongodb данными

```shell
./scripts/mongo-init.sh
```

## Как проверить

### Схема расположена:
https://github.com/ravenpl1/architecture-sprint-2/blob/sprint_2/sprint2_all-schemes.drawio

### Общее количество документов, количество документов в каждом шарде, количество реплик в каждом шарде выводиться в консоле во время выполнения скрипта ./scripts/mongo-init.sh
Записи в консоле:  
Количество записей в БД: значение  
Количество записей в shard: значение  
Количество реплик в shard: значение  

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080
